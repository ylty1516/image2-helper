# Style Prompt Cookbook

Use these as compact skeletons. Replace bracketed fields and remove anything irrelevant.

## Photography

### Documentary Photo

```text
Create a documentary photograph, [aspect ratio].
Subject: [person/place/action].
Scene: [real location and time].
Camera: available light, imperfect but intentional framing, natural lens perspective, slight motion softness if appropriate.
Details: real clothing texture, contact shadows, ordinary background objects, no staged perfection.
Avoid: beauty-retouch skin, fake cinematic haze, HDR clarity, symmetrical cleanup, floating props.
```

### Editorial Portrait

```text
Create an editorial portrait, [aspect ratio].
Subject: [person/character] with [wardrobe/material].
Production: controlled styling, purposeful pose, real modifier shadows, restrained retouching.
Composition: [close/medium/full body], intentional negative space, background that supports the subject.
Avoid: plastic skin, over-sharp eyes, impossible fabric, random rim lights, generic model pose.
```

### Analog Snapshot

```text
Create an analog film snapshot, [aspect ratio].
Subject: [subject].
Scene: [casual moment].
Camera/finish: film-like highlight rolloff, muted color crossover, visible grain, small focus imperfection, flash or daylight falloff.
Avoid: fake heavy scratches, digital HDR, perfect skin, sterile whites.
```

### Product Photo

```text
Create a product photograph, [aspect ratio].
Product: [object/material/scale].
Set: [surface/background].
Light: [softbox/window/hard sun] with grounded contact shadow and realistic reflections.
Details: material thickness, seams, manufacturing marks, label-safe blank space.
Avoid: fake text, impossible glass, floating product, showroom void, glossy everything.
```

## Anime / Comic

### Hand-Drawn Anime Still

```text
Create a hand-drawn anime still, [aspect ratio].
Subject: [character/action].
Layout: readable key pose, clear silhouette, camera-aware staging.
Line/color: clean animation contours, flat local colors, hard-edged two-tone cel shadows, simple highlights.
Background: hand-painted poster-color/gouache feel, simplified brush masses, atmospheric color harmony.
Avoid: glossy 3D hair, airbrushed gradients, random rim lights, over-detailed costume noise.
```

### Manga Panel

```text
Create a black-and-white manga panel, [aspect ratio].
Subject: [character/action].
Line: clean ink contours, confident black fills, controlled screentone, readable silhouette.
Composition: panel-aware framing, action lines only where needed, no fake dialogue text.
Avoid: gray mush, random hatching, unreadable hands, fake sound effects.
```

### Webtoon Panel

```text
Create a vertical webtoon panel.
Subject: [character/story beat].
Rendering: clean character shapes, readable facial acting, simplified background, selective gradients.
Layout: vertical-scroll composition with speech-safe negative space.
Avoid: fake speech text, over-rendered hair shine, cluttered panel, hidden anatomy.
```

### Retro Anime Frame

```text
Create a retro anime frame, [aspect ratio].
Subject: [character/scene].
Look: painted cel finish, thicker contour lines, limited palette, bolder shadow shapes, analog compositing softness, subtle film dust.
Avoid: modern glossy gradients, 3D depth blur, neon effects everywhere, ultra-clean vector linework.
```

## Digital / Game / UI

### Flat Vector Editorial

```text
Create a flat vector editorial illustration, [aspect ratio].
Concept: [idea/metaphor].
Design: simple geometric shapes, limited palette, consistent stroke/corner style, clear hierarchy, intentional negative space.
Avoid: random gradients, inconsistent icon style, fake 3D shadows, decorative clutter.
```

### Isometric Technical

```text
Create an isometric technical illustration, [aspect ratio].
Subject: [system/object/space].
Structure: consistent isometric angle, aligned grid, simplified components, clear hierarchy, controlled shadows.
Text: no invented labels; leave callout-safe spaces.
Avoid: mixed perspectives, fake tiny text, impossible architecture.
```

### Pixel Art Scene

```text
Create a pixel art scene, [aspect ratio].
Subject: [scene/action].
Pixel rules: fixed pixel grid, limited palette, deliberate clusters, readable silhouette, no anti-aliased blur.
Composition: [side-view/top-down/isometric] with clear gameplay readability.
Avoid: pseudo-pixel noise, smooth gradients, inconsistent pixel size, painterly texture.
```

### Low-Poly Game Asset

```text
Create a low-poly game asset render, [aspect ratio].
Object/scene: [asset].
3D style: visible polygon planes, simplified geometry, consistent material roughness, ambient occlusion, clear silhouette.
Avoid: melted geometry, photoreal texture on simple forms, glossy everything, floating parts.
```
